# Youtube-and-Twitter-downloader-telegram-bot-rust

this code needs your account to be a bot on telegram, you can create one by talking to [@BotFather](https://t.me/BotFather) and following the instructions.

this bot is a telegram bot that can download videos from youtube and twitter, and send them to you on telegram.

## How to use

1. Clone this repository
2. Install the required dependencies
3. Set up your Telegram bot token
4. Set up your bot password
5. Set up the maximum file size limit
6. Set up your twitter cookies (optional, but recommended for downloading videos from twitter)
